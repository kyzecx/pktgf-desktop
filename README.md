一款桌面端皮卡堂像素搭配工具，支持 Windows / macOS / Linux。
本地运行、无需登录，资源缓存在本机，断网也可以继续查看和编辑已经加载过的内容。

---

## 功能

- **在线衣柜**：发型、连身、头饰、面具、眼镜、上衣、裤子、外套、背饰、翅膀
- **大模型 / 小模型**：100×150 大模型与 40×60 小模型，小模型可选正面、背面
- **双模型预览**：大图在左，小模型正/背在右，也可以单独查看某一种
- **分类图标**：直接使用游戏内的衣柜分类图标
- **列表设置**：搭配与图鉴共用二级菜单，切换大图 / 小图、每行数量与排序
- **搜索**：顶部搜索框，按空格聚焦；下拉显示带缩略图的历史记录
- **存档管理**：独立存档页，汇总搭配与后续装修等工具的存档；支持搜索、筛选、排序、载入、删除、导入导出
- **自建素材**：导入官方格式静态图；动态素材同时导入帧条，支持动画播放与 GIF 导出
- **图鉴**：服饰 / 家具 / 宠物分类浏览；服饰可切大小图，宠物可切本体 / 蛋；逐帧勾选、GIF 或未裁切雪碧图原图导出，自动按「分类 / 物品代码_名称」建立文件夹
- **卖货图**：服装 / 道具双模版，支持名称、价格、已卖出、拖动组合、间距与每行数量自定义，生成结果自动留档
- **主题**：浅色 / 深色模式，侧栏按钮切换
- **导出**：按当前选择的模型导出 PNG / GIF
- **表情**：独立表情菜单，显示实际表情图
- **自动更新**：从 GitHub Releases 检查并下载新版本安装包
- **快捷键**：`⌘S` / `Ctrl+S` 保存，`⌘E` / `Ctrl+E` 导出 PNG，`⇧⌘E` / `Ctrl+Shift+E` 导出 GIF
