# 皮卡堂工坊 0.4.0 · 建造 · 装修大版本

- 新增建造 / 装修页：45° 网格自动拼接，覆盖 281 个房型（拼接房、整图房、TMX 场景房），92 个拼接房型几何自检全部通过。
- 家具 15 632 件，含占地、朝向、挂墙、叠放、深度排序、灯光叠加与 Posy / Bonsai 遮罩；拖动、旋转（含旋转后占地互换）、多选与对齐、图层面板（按真实绘制顺序）。
- 角色与 NPC：40×60 小模型 17 层合成，官方 255 组角色动作与 45 组 NPC 动作；A* 点地走位、拖拽落位、点家具开门 / 换状态 / 坐下。
- 自定义导入：家具、角色包、动作编辑器（时间轴 + 逐帧选图 + JSON 导入导出），全部走官方渲染路径。
- 导出：确定性的 `frameAt(t)` 渲染，PNG / GIF / PNG 序列 / MP4（MP4 需系统 ffmpeg，未安装时降级提示）；房间存档可导出 `.pktroom` 分享，导入时校验缺素材。
- 资源自动更新：每 5 分钟检查官方版本，发现更新就在应用内重建目录（写入 userData 并热替换），无需等待新版本发布；重建失败自动回落随包快照。
- 工作台改版：功能入口、资源规模、搭配与房间存档混排；导出可固定保存目录、保存后自动打开文件夹。
- 设置：每页可自定义快捷键、更新日志。
- 修复：动作 `hair` 字段被误当头部帧导致的头部闪烁；服饰只取第 0 帧导致坐下时站立腿与坐姿腿叠两层；旋转后占地网格不跟随；顶部菜单「导出」按钮嵌套 `<button>` 的告警。
