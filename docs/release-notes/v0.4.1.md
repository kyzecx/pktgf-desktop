# 皮卡堂工坊 0.4.1 · 卖货图 · 搭配存档与部件标价

- 卖货图支持把已保存的搭配存档直接作为条目：在存档页悬停搭配点「卖货图」，或在卖货图编辑器的「搭配存档」里加入。
- 整套搭配可按「整套」或任意多个部件分别设置名称和价格，适合整套出售，也可以拆卖发型、上衣等单个部件。
- 名称和价格统一画在图片下方的标签区，长文本自动截断，不会遮挡立绘；多行标签带浅色底分组。
- 价格输入只接受数字和小数点（最多两位），中文输入法打出的「。」「．」「｡」「·」会自动转成小数点。
- 卖货图记录内嵌搭配快照，原搭配存档删除后仍能还原；移除图鉴单品会同步图鉴页的勾选状态。
- 修复：双图模式下价格文字与第二张背面小图重叠；搭配部件名称被「显示名字」开关误隐藏。
